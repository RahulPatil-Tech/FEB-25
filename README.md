## **Installation Instructions** 📥

Follow these steps to get the project up and running locally:

### **Prerequisites** ⚙️
Ensure that you have the following installed:
- **Git** (for version control) 🧑‍💻
- **Java** (for Java-based modules) ☕
- **Python** (for Python-based modules) 🐍
- **MySQL/PostgreSQL** (for database management) 🗃️

You can install these using the following commands:

```bash
# Install Git
sudo apt install git

# Install Java (OpenJDK)
sudo apt install openjdk-11-jdk

# Install Python
sudo apt install python3

# Install MySQL or PostgreSQL
sudo apt install mysql-server
# or
sudo apt install postgresql
```

# **Cloning the Repository 📂** 
Clone the repository to your local machine:
```
git clone https://github.com/RahulPatil-Tech/FEB-25.git
cd FEB-25
```


# **Usage 🚀**
After cloning the repository, follow these steps to run the application:

## *For Python-based Modules 🐍:*
1. Navigate to the Python folder.
2. Install dependencies:
```
pip install -r requirements.txt
```
3. Run the application:
```
python app.py
```
# *For Java-based Modules ☕:*
1. Navigate to the Java folder.
2. Compile and run the Java program:
```
javac Program.java
java Program
```
# *Database Setup 🗃️*
1. Set up the database by running the SQL scripts provided in the /database folder. You can run the following command to set up the tables:
```
mysql -u root -p < setup.sql
```
Or for PostgreSQL:
```
psql -U postgres -f setup.sql
```
